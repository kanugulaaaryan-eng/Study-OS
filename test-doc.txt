Supervised learning is a machine learning approach where a model learns from labeled examples. Each training example consists of an input vector and a corresponding target label. The goal is to learn a mapping function that can predict labels for new, unseen inputs.

Key concepts:
- Training data: pairs of (input, label)
- Model: a function that maps inputs to outputs
- Loss function: measures how wrong predictions are
- Optimization: adjust model parameters to minimize loss
- Generalization: model should work on new data

Common algorithms:
1. Linear regression for continuous targets
2. Logistic regression for binary classification
3. Decision trees for interpretable models
4. Neural networks for complex patterns
5. Support vector machines for high-dimensional data

Evaluation metrics:
- Accuracy, Precision, Recall, F1 for classification
- MSE, MAE, R² for regression

Cross-validation helps estimate generalization performance.
